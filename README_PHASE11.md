# Արմ Կերպ — Phase 11: Multiplayer Lobby Beta

Այս փաթեթը Phase 10-ի ամբողջական նախագծի շարունակությունն է՝ ներառյալ SSE parser-ի ուղղումը։

## Նոր հնարավորություններ
- Ready վիճակ յուրաքանչյուր խաղացողի համար. Host-ը կարող է սկսել միայն եթե առնվազն 2 մասնակից կա և բոլոր հյուրերը ready են։
- Multiplayer Lobby-ի live մասնակիցների ցուցակ՝ պատրաստության նշաններով։
- Հոսքային chat. հաղորդագրությունները ցուցադրվում են սենյակի անդամներին (վերջին 30 հաղորդագրությունները՝ RAM-ում, մինչև սերվերի վերագործարկում)։
- Host-ի ձեռքով փոխանցում ուրիշ մասնակցի, միայն փուլերի միջև։
- Host-ի կարգավորումներ՝ 30, 45, 60 կամ 90 վրկ., 1–5 փուլ։
- Rematch՝ վերականգնում է live round-երը, ready-ները և **զրոյացնում է տվյալ սենյակի live միավորները**. պահանջում է հաստատում։

## WebStorm
1. Բացիր `armkerp-build` պանակը որպես նախագիծ։
2. Terminal-ում՝ `npm install` (առաջին անգամ), հետո՝ `npm start`։
3. Բացիր `http://localhost:3000` և առնվազն երկու տարբեր Online հաշիվներով միացիր միևնույն սենյակին։
4. Հյուրերը սեղմում են «Պատրաստ եմ», Host-ը կարող է սկսել։

## Տվյալների կարևորություն
Եթե արդեն ունես օգտատերերի տվյալներ, **մի ջնջիր քո գործող `*.db` ֆայլը**։ Նոր ZIP-ում SQLite բազա ներառված չէ։ Սերվերը ստեղծում է նոր `live_room_settings` և `live_room_ready` աղյուսակները։ Եթե ցանկանում ես պահպանել հին հաշիվները, նախ պահուստավորիր քո գործող տվյալների բազան և աշխատիր նրա հետ նույն server պանակում։

## Սահմանափակումներ
- Դեռ beta է. միասնական երկու սարքով թեստ չի կատարվել ստեղծման միջավայրում։
- Միաժամանակյա socket չէ, օգտագործվում է authenticated SSE + POST։
- Սենյակի Host-ի փոխանցումը ձեռքով է, ոչ ավտոմատ անջատման ժամանակ։
- Chat-ը տվյալ սերվերի RAM-ում է (ոչ մշտական) և ամենախիստ moderation համակարգ չունի։ Չօգտագործել անծանոթների համար բաց հանրային սերվերում՝ առանց անվտանգության լրացուցիչ քայլերի։
- Միայն `npm start`-ով աշխատող Node backend-ն է աջակցում live multiplayer-ը. GitHub Pages-ը առանձին backend է պահանջում։
