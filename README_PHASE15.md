# Arm Կերպ — Phase 15 (Beta)

## Նորություններ
- Live սերվերի միացման, ընդհատման ու ավտոմատ վերամիացման տեսանելի կարգավիճակ (SSE-ի ներկա reconnect loop-ը պահպանված է)։
- WebRTC ձայնային կապի վիճակ, RTT և կուտակային packet loss՝ երբ բրաուզերը վերադարձնում է տվյալները։
- Ձայնային կապի ավտոմատ վերամիացման փորձեր (մինչև 5 փորձ՝ աստիճանաբար աճող ընդմիջումներով), կրկին փորձելու կոճակ։
- Միկրոֆոնը կրկին չի բացվում առանց օգտատիրոջ սկզբնական թույլտվության, և սենյակ փոխելիս անջատվում է։

## Ինչպես փորձել WebStorm-ում
1. Extract ZIP, բացել armkerp-build պանակը։
2. `npm install` և `npm start`։
3. Բացել http://localhost:3000։ Երկու տարբեր հաշիվներով միանալ սենյակին, Voice Chat-ին։
4. Ստուգել ձայնը և RTT-ն, հետո ժամանակավորապես անջատել մեկ խաղացողի կապը և վերադարձնել։

## Սահմանափակումներ
- Voice peer-to-peer կապը որոշ ցանցերում պահանջում է TURN relay․ այս նախագծում կա միայն հանրային STUN սերվեր։
- Packet loss-ը կուտակային գնահատական է, ոչ իրական ժամանակի speed test։
- Server stream-ի կարգավիճակը SSE-ի վիճակն է, ոչ չափված ping։
- Թեստավորեք նախ տեղային ցանցում։ Արտաքին սարքում միկրոֆոնի համար HTTPS է պետք։
- Գործող SQLite բազան այս ZIP-ում ներառված չէ․ պահուստավորիր հինը նախքան նախագծի տեղափոխումը։
